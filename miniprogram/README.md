# 云游壁画修复师 - 微信小程序

标准微信小程序空白工程模板。

## 目录结构

```text
miniprogram/
├── pages/
│   ├── index/            # 首页（功能引导与概览）
│   │   ├── index.js
│   │   ├── index.json
│   │   ├── index.wxml
│   │   └── index.wxss
│   └── logs/             # 日志页
│       ├── logs.js
│       ├── logs.json
│       ├── logs.wxml
│       └── logs.wxss
├── utils/
│   └── util.js           # 常用工具函数
├── app.js                # 小程序入口逻辑
├── app.json              # 全局配置（页面路由、窗口样式）
├── app.wxss              # 全局通用样式
├── project.config.json   # 微信开发者工具项目配置文件
└── sitemap.json          # 搜索引索配置
```

## 如何运行 / 导入开发

1. 打开 **微信开发者工具**（WeChat DevTools）。
2. 点击 **「导入项目」**（或「+」号）。
3. **项目名称**：输入 `云游壁画修复师`。
4. **目录**：选择本文件夹路径：
   `c:\Users\Asus\Desktop\Ancient Chinese Texts Project\miniprogram`
5. **AppID**：可填入您自己的测试 AppID，或选择 **「测试号 / 游客模式」**。
6. **开发模式**：选择 **小程序**。
7. 点击 **「确定」** 即可在模拟器中预览与开发。
